  # 🧩 알고리즘 스터디


  ## 🚀 진행 방식

  1. 매주 이슈에 공지된 5문제 확인
  2. 개인 작업 브랜치에서 문제 풀이 후 커밋
  3. 스터디 당일 오전 9시 전까지 PR 생성
  4. 스터디 진행 시 풀이 및 코드 공유
      - 문제별 담당자를 지정하여 발표
      - 다른 풀이가 있을 경우 **시간 복잡도 및 접근 방식** 비교
  5. 스터디 종료 후 PR 머지


  ## 🌿 규칙

  - 깃허브 ID로 브랜치를 만들고, PR을 통해서 main에 반영

  - 한 주 분량의 풀이를 한 브랜치에서 작업하고, 완료되면 하나의 PR로 올림
  - 작업 브랜치: **`{본인 깃허브 아이디}`** 형식
    - 예) `sor999`


  ### 폴더/파일 작명 규칙

  - **주차 폴더**: `week{2자리}`
      - 예) `week01`, `week02`
  - **문제 폴더**: `{문제이름}` 
      - 예) `네트워크`, `전력망을둘로나누기`
    - 띄어쓰기는 삭제
  - **풀이 파일명**: `{본인 깃허브 아이디}.{확장자}`
      - 예) `sor999.py`


  ### 커밋 컨벤션

  | type | 설명 | 예시 |
  | --- | --- | --- |
  | `add` | 문제 풀이 추가 | `add: 문제 이름 ` |
  | `docs` | README 추가/수정 | `docs: week01 문제 목록 정리` |
  | `refactor` | 개선 | `refactor: 변수명 정리` |
  | `fix` | 개선 | `fix: 오타 수정` |
  


  ### PR 규칙
  1. PR 제목 **주차, 알고리즘 주제, 이름**을 알 수 있게 작성
      - 예시:  `[1주차] 그리디 - 홍길동`
  2. PR 본문에 해당 주차 이슈번호를 포함
      - ```- #17```
